---
question: "De quoi est constitué le jeu Ki-tämi ?"
---

Le jeu Ki-tämi comprend :

- Le jeu vidéo pour l'enfant
- Le guide pédagogique imprimé du parent ou de l'enseignant
- Un accès sécurisé à la plateforme numérique interactive pour faire les activités ludiques complémentaires du guide
- Un jeu de société : jeu de plateau ou jeu de cartes
